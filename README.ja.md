# PG3D カスタムスキン インポーター

[English](README.md) | [日本語](README.ja.md)

Pixel Gun 3D のローカルスキンを様々な形で編集できる、静的HTML製のツールです。

> [!WARNING]
> すでにローカルスキンがある場合は、必ず「`.reg から読み込む`」を使用してください。でないと、既存のローカルスキンが上書きされてしまいます。
> ローカルスキンには、下記の画像のようにスキン名の横にスマートフォンのアイコンが表示されています。
>
>![alt text](readme_images/local_skin_icon.png)
>
>`.reg`ファイルの取り出し方は[こちら](#regファイルを取り出す方法regedit)から確認できます。

リポジトリ: https://github.com/mof-22/PG3D_skin_importer

ホストされたページを使用する場合は https://mof-22.github.io/PG3D_skin_importer/ にアクセスしてください

## 紹介

このツールでは、`.reg`ファイルを介して次のような編集が可能になります。

- スキンの一括インポート
- ゲーム内スキンのエクスポート(画像としての一括書き出し)
- 名前、順番の変更

その他にも様々な機能があります。詳しくは[使い方](#使い方)をご覧ください。

### 利点

- **インストール不要** — 完全に静的なWebページとして動作します。`index.html`を直接開くか、[ホストされたページ](https://mof-22.github.io/PG3D_skin_importer/)を開くだけで、ダウンロードせずに使用することも可能です。
- **自動最適化** — スキンの第2レイヤーをベースレイヤーへ合成、アイラインを上書きするドットの除去、腕の幅を4pxへ自動変換するなど、Minecraft形式のスキンからの見た目の崩れを最小限に抑えるよう修正します。
- **スキンごとの個別設定** — スキンごとに設定を保持するため、修正済み・未修正が混在したスキン群でも、それぞれ個別に調整できます。オプションは全スキン一括、または選択したスキンだけへの一括適用も可能です。
- **3Dプレビュー** — オプションによる変化やゲーム内での見た目を、その場で簡単に確認できます。
- **すべてローカルで完結** — 画像処理やファイルの読み書きはすべてブラウザ内で行われます。外部へアップロードされることはありません。

### 必要環境

- **Windows** — ツール自体(画像加工・`.reg`の読み込みや生成)はOSを問わず動作しますが、生成した`.reg`をレジストリへ反映する操作がWindows専用のため、実質的にWindows環境でのみ意味を持ちます。
- **WebGLに対応したモダンブラウザ**(Chrome、Edge、Firefoxなど) — ツールの動作および3Dプレビューに必要です。

## 使い方

### クイックスタート

1. ブラウザでツールを開きます。
2. スキン画像を追加する、または既存の`.reg`ファイルを読み込みます。
3. 必要に応じて加工オプションを調整し、3Dプレビューで確認します。
4. `.reg`ファイルを生成(または画像をダウンロード)し、ゲームに反映します。

### スキンの追加

![alt text](readme_images/UI_add_skins.png)

- **画像を選択** — 1つ以上の画像ファイルを選択します。選択した画像はその場で現在のオプションを使って加工され、一覧に追加されます。既に一覧にあるファイルと内容が重複する場合は自動的にスキップされます。
- **.regから読み込む** — `.reg`ファイルからスキンを読み込みます。**ゲーム内にすでにローカルスキンが存在する場合は、必ずこちらから始めてください**(冒頭の注意もご参照ください)。`.reg`ファイルの取り出し方は[こちら](#regファイルを取り出す方法regedit)から確認できます。

### 加工オプション

![alt text](readme_images/UI_processing_options.png)

- **スキンの自動加工** — 以下すべての加工の親スイッチです。オフにすると画像は一切変更されません。
- **腕の上面をX軸反転** — PG3D側の腕top面の描画挙動に合わせるための補正です。特別な理由がない限りONのままを推奨します。
- **レイヤーのアイライン上書きを除去** — レイヤー側のドットのうち、ベーススキンのアイラインを覆ってしまう数ピクセルを消します。人型のスキンでは一般的に有効ですが、記号的・幾何学的なデザインのスキンでは問題が起きる可能性があります。
- **レイヤー上書きのスキップ** — 頭/胴体/腕/脚の「第2レイヤー」(服など)は通常ベーススキンへ合成されます。このチェックボックス群で、合成自体をスキップしたり、特定の部位だけスキップしたりできます。
- **使用する腕/脚テクスチャ(右/左)** — クラシック形式のスキンは、腕・脚それぞれ片側分のデータしか持たず、反対側は反転コピーで生成されます。このオプションで、どちら側のデータを元にするかを選べます(データが片側にしか無い場合や、単純にもう一方のデザインを使いたい場合に便利です)。
- **腕の幅判定** — スキンの腕部分を補正します。基本的には自動で4px幅に補正されますが、自動検出が完璧でない場合に備え、手動での調整も可能です。
- **全スキンに現在のオプションを適用** — 一覧の全スキンの個別設定を、現在パネルに表示されている内容で一括上書きし、再加工します。

### スキン一覧

![alt text](readme_images/UI_skin_list.png)

- **チェックボックス** — 複数選択用です(一覧上部の「全選択」「選択に現在のオプションを適用」「選択を削除」で使います)。
- **サムネイル** — スキンの展開図(テクスチャ全体)を確認できます。
- **名前** — 編集可能です。初期値にはファイル名、または(`.reg`読み込みの場合は)ゲーム内名が入ります。
- **新規/読込済みバッジ** — そのスキンが画像ファイル由来か、`.reg`由来かを確認できます。
- **↑ / ↓** — ボタンで1つずつ移動します。**Shiftキーを押しながらクリック**すると、一覧の最上段/最下段まで一気に移動します。
- **×** — そのスキンを削除します。

**固定表示(ピン留め)について:** ホバーでプレビューが更新される仕様上、プレビューへ向かう際にカーソルが一覧上を通過すると、意図せず表示中のスキンが切り替わることがあります。行の(名前欄・ボタン・チェックボックスを除く)どこかをクリックすると、そのスキンにプレビューを固定できます。固定中は他の行にホバーしてもプレビューは変わりません。もう一度その行をクリックするか、プレビュー下の「📌 固定中」の文字をクリックすると固定を解除できます。

### 3Dプレビュー

- **ドラッグ** — モデルを回転します。
- **ホイール** — ズームします。
- 背景は現在のテーマに合わせて変化します。

### 出力

![alt text](readme_images/UI_export.png)

- **スキン名を書き出す** — チェックすると、各スキンに付けた名前が`.reg`に書き込まれ、ゲーム内で表示されます。チェックを外した場合も名前の値自体は書き出されますが空欄になります。ファイル名がランダムなハッシュ値などの場合に便利です。
- **.regファイルを生成** — 各スキンをそれぞれ自身のオプションで再加工したうえで、レジストリへの反映用`.reg`ファイルをダウンロードします。
- **画像を一括ダウンロード** — 読み込んだスキンをPNGとして1つのZIPにまとめてダウンロードします。ゲーム内のスキンを画像として取り出したい場合に便利です。

### `.reg`ファイルを取り出す方法(regedit)

1. `Win` + `R`を押し、`regedit`と入力します。
2. 上部のパス表示欄に`HKEY_CURRENT_USER\Software\Pixel Gun Team\Pixel Gun 3D`を入力します。
3. 上部メニューの「ファイル」から「エクスポート」を選択します。
4. 任意の場所に好きな名前で保存します。

*このツールは`User Skins_h1196497400`と`User Name Skins_h1318731231`以外のキー・値を読み取ることはありませんが、気になる場合は手動でその他の情報を削除してから読み込んでください。*

## FAQ

**新しく`.reg`を生成すると、既にゲームに入っているスキンとマージされますか？それとも置き換えられますか？**
置き換えられます。レジストリの値は全スキンを1つのまとまりとして保持しているためです。既に導入済みのスキンを残したい場合は、先に現在の`.reg`をツールに読み込んでから、スキンを追加・編集し、その一覧全体から改めて生成してください。取り出し方は[こちら](#regファイルを取り出す方法regedit)をご覧ください。

**使用しても安全ですか？アカウントがBANされたりしませんか？**
本ツールが編集するのはレジストリ上の限られたデータのみで、サーバーとの通信は一切行いません。ただし、ゲーム内で通常作成した場合と全く同じ挙動になる保証はできないため、問題が起きないとは断言できません。あらかじめご了承ください。

**加工後、腕の裏側や手の部分に黒い部分が存在します。**
そのスキンのオプションで「腕の幅判定」を確認してください。判定位置の付近に作者のサインや不透明な背景などがあるスキンは、まれに「既に4px幅」と誤判定されることがあります。この場合、本来変換されるべき部分が変換されずに透明のまま残り、ゲーム内では透明部分が黒く表示されるため、腕の一部が黒く見えてしまいます。該当する場合は「3pxとして変換する」に手動で切り替えてください。
